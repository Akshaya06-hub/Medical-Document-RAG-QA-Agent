# Medical Document RAG & QA Agent

An intelligent Retrieval-Augmented Generation (RAG) pipeline designed to ingest unstructured medical and insurance guideline documents, embed text chunks, and provide precise, context-aware answers with source citations.

## 🚀 Features
* **Document Ingestion & Chunking:** Parses text documents and splits them into optimized semantic chunks.
* **Vector Embeddings:** Computes and indexes vector embeddings for fast similarity search.
* **LLM Query Engine:** Leverages LLM APIs to generate accurate answers strictly grounded in the retrieved document context.

## 🛠️ Tech Stack
* Python
* LangChain / LlamaIndex concepts
* Google GenAI / OpenAI APIs
* NumPy / Pandas
